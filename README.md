# ADLS — Affluent Discretionary Liquidity Stress Program

**Research-only.** This system studies liquidity stress in affluent-household
discretionary spending as a **leading-indicator research signal** for markets.
It turns observations into verified, labeled findings and human-readable
reports. It informs a human; it never acts. It does not buy, sell, trade,
place orders, or move funds, and nothing in this repository is financial advice.

Part of the [Decision Systems Playbook](https://github.com/Its-a-space-station/Decision_systems_playbook)
family and governed by its safety policy (local copies in `docs/`).
